## CSS样式


### 边框模型
* 参考: https://www.w3school.com.cn/css/css_boxmodel.asp


* 模型图

```c
///  *---------------- margin(外边距) ------------------*
///  |  *------------- border(边框) -----------------*  |
///  |  |  *---------- padding(内边距) -----------*  |  |
///  |  |  |  *--------------------------------*  |  |  |
///  |  |  |  |                                |  |  |  |
///  |  |  |  |        element(元素/wnd)       |  |  |  |
///  |  |  |  |                                |  |  |  |
///  |  |  |  *--------------------------------*  |  |  |
///  |  |  *--------------------------------------*  |  |
///  |  *--------------------------------------------*  |
///  *--------------------------------------------------*
```

* 背景应用于由内容(元素wnd)和内边距、边框组成的区域
